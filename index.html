eBay Listing System

Privacy Policy

How this privately operated seller tool accesses, uses, stores, and protects data when the authorized account owner connects eBay.

Effective date: October 11, 2026  |  Contact: kangkangzhu918@gmail.com

eBay Listing System is an independent, privately operated software tool. It is not an official eBay product and is not endorsed by eBay. The tool is currently intended for use by its authorized seller account operator, not as a general public service.

1. Data we access

When the eBay account owner authorizes the application, it may access information made available through the approved eBay APIs and scopes needed for its enabled features, such as:

  • Seller account and business policy information, marketplace settings, and shipping locations.
  • Listing content, product details, images, item identifiers, variation attributes, prices, and inventory levels.
  • Order or fulfillment-related information, which may include buyer name, shipping address, and order details, only when an enabled feature requires it and the authorized API permissions allow it.
  • OAuth authorization credentials, including short-lived access tokens and refresh tokens issued by eBay.
  • Local diagnostic records, API status/error responses, and listing audit reports created during use.

The tool does not ask for or store the seller's eBay account password.

2. How we use the data

The data is used to authenticate seller-approved requests, research and prepare product listings, create or revise listings when explicitly authorized, check inventory and business policies, and read back results to detect errors or duplicate submissions. Order data, if accessed, is used only for authorized order and fulfillment functions. Information is not used to build advertising profiles or sold to data brokers.

3. Authorization and seller control

The seller signs in through eBay's OAuth authorization flow and chooses whether to grant the requested permissions. Access tokens may be renewed automatically using an eBay-issued refresh token while that permission remains valid. The seller can revoke the application's access through the eBay account's connected-app or third-party authorization settings. A revoked or expired authorization must be renewed through eBay if the tool is to continue accessing protected data.

4. Storage and security

The current Windows application keeps application credentials and seller OAuth tokens encrypted in a local Windows user-scoped credential store using the Windows Data Protection API (DPAPI). Local listing plans, reference product information, and audit records may be stored in files on the operator's computer. The operator is responsible for limiting device and file access, maintaining backups, and securing the local account.

Production API secrets and seller tokens must not be placed in the public privacy-policy repository. The application's separate source-code repository is not a token-storage service. No method of storage or transmission provides absolute security.

5. Sharing and service providers

The application communicates with eBay's API services to perform requested seller operations. This public policy page is hosted by GitHub Pages, so GitHub may process web access and infrastructure information under its own privacy policies. The tool is not currently designed to transmit seller tokens or buyer records to the public GitHub Pages website. If new external processors or hosted features are introduced, this policy should be updated before they are used.

6. Retention and deletion

Locally stored tokens, listing data, and audit files may remain until deleted by the account operator or as needed for troubleshooting and audit history. The operator can revoke eBay permissions, delete locally stored credentials and application-generated files, and request assistance with data access or deletion using the contact below. Some information may remain in eBay's own systems under eBay's policies or in backups until they expire or are deleted.

7. Rights and choices

Requests will be reviewed with regard to identity verification, applicable law, and the information actually controlled by this tool. To exercise rights concerning information held directly by eBay, contact eBay through its privacy channels.

8. Policy changes

This policy may be updated as the application's features, data uses, legal obligations, or service providers change. The effective date above will be updated when material changes are published. Continued use should be based on the most recent publicly available version.
